# יפן 2026 · בר ונועה

Itinerary web app for our October 2026 Japan trip — an interactive map (Leaflet + OpenStreetMap) with the six stops pinned along the route, and tappable cards that open each stop's day plan.

**Live:** https://barziee.github.io/japan-2026/

Single static page (index.html), Hebrew/RTL, works on mobile. No personal booking references are published here.
